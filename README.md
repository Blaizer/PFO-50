PFO 50 v0.6.0
=============

PFO 50 (Play Forever Online 50) is a mod for UFO 50 that adds online
multiplayer support to UFO 50 v1.8.9.

Installation
------------
1. In your Steam Library, right click UFO 50 and select "Properties...".
   Go to "Installed Files" on the left, and then click "Verify integrity of
   game files". This will ensure UFO 50 is up to date and without any mods
2. Run the (included) "GMLoader", then close it. This needs to be done only
   once to ensure it has the correct permissions
3. Run "UFO 50 Mod Loader" and click "Install Mods" in the top left corner,
   with the "PFO 50" mod ticked
4. Run UFO 50, you should see "PFO 50" and the correct version number in the
   lower left corner

You can uninstall PFO 50 by doing the first step again, or by clicking the
"Uninstall Mods" button in the Mod Loader.

Controls
--------
[F2/F3] - Show/hide some networking and performance information

Input Delay
-----------
PFO 50 uses input delay to allow both players to play simultaneously online.
The input delay is automatically chosen based on your connection quality to
the other player. Usually the input delay will be the same for both players,
but for some turn-based games the input delay will favor the current player.
